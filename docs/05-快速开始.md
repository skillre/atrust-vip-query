## 一、30秒快速体验


## 四、配置说明

### 4.1 aTrust 配置

```yaml
atrust:
  host: "https://192.168.1.100:4433"  # 改成你的aTrust地址
  api_id: "1234567"                    # 从控制台获取
  api_key: "abc123def456"              # 从控制台获取
```

**获取API密钥：**

1. 登录 aTrust 控制台
2. 进入 系统管理 → 开放平台 → Open API
3. 点击"显示密钥"获取 API ID 和 API Key

### 4.2 Syslog 配置

```yaml
syslog:
  enabled: true
  host: "0.0.0.0"
  port: 514          # 默认514，如被占用可改为1514
  protocol: "udp"
```

**如果使用非标准端口（如1514）：**

1. 修改 config.yaml 中的 port
2. 在 aTrust 控制台配置 Syslog 转发时填写对应端口

## 五、常见操作

### 5.1 查看日志

```bash
# 实时查看日志
tail -f logs/app.log

# 查看最近100行
tail -100 logs/app.log
```

### 5.2 查看数据库

```bash
# 使用sqlite3命令行
sqlite3 data/vip_data.db

# 查看表结构
.schema

# 查看数据
SELECT * FROM users LIMIT 10;
SELECT * FROM vip_records LIMIT 10;
```

### 5.3 重启服务

```bash
# 找到进程ID
ps aux | grep python

# 杀死进程
kill -9 <PID>

# 重新启动
python app.py
```
