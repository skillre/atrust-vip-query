# 部署指南

## 一、环境准备

### 1.1 系统要求

| 项目 | 最低要求 | 推荐配置 |
|------|---------|---------|
| 操作系统 | Linux / Windows / macOS | Linux (Ubuntu 20.04+) |
| CPU | 1核 | 2核 |
| 内存 | 2GB | 4GB |
| 磁盘 | 5GB | 10GB |
| Python | 3.8+ | 3.10+ |
| 网络 | 能访问aTrust 4433端口 | 稳定网络连接 |

### 1.2 依赖软件

| 软件 | 版本 | 说明 |
|------|------|------|
| Python | 3.8+ | 运行环境 |
| pip | 最新 | 包管理器 |
| Git | 最新 | 代码版本管理（可选） |

## 二、安装步骤

### 2.1 获取代码

```bash
# 方式1：直接复制文件
# 将项目文件复制到目标服务器

# 方式2：Git克隆（如果有仓库）
git clone <repository_url>
cd 虚拟IP查询
```

### 2.2 创建虚拟环境（推荐）

```bash
# 创建虚拟环境
python -m venv venv

# 激活虚拟环境
# Linux/macOS:
source venv/bin/activate

# Windows:
venv\Scripts\activate
```

### 2.3 安装依赖

```bash
# 安装Python依赖
pip install -r requirements.txt
```

### 2.4 配置文件

```bash
# 复制配置模板
cp config.yaml.example config.yaml

# 编辑配置文件
vim config.yaml
```

#### 配置项说明

```yaml
# aTrust 配置
atrust:
  host: "https://192.168.1.100:4433"  # aTrust控制台地址
  api_id: "YOUR_API_ID"                # API ID
  api_key: "YOUR_API_KEY"              # API密钥

# Syslog 配置
syslog:
  enabled: true
  host: "0.0.0.0"
  port: 514
  protocol: "udp"  # udp 或 tcp

# 数据库配置
database:
  path: "./data/vip_data.db"

# Web 界面配置
web:
  host: "0.0.0.0"
  port: 8501

# API 服务配置
api:
  host: "0.0.0.0"
  port: 8000
```

### 2.5 初始化数据库

```bash
# 方式1：自动初始化（启动时自动创建）
python app.py

# 方式2：手动初始化
python scripts/init_db.py
```

## 三、启动服务

### 3.1 开发环境启动

```bash
# 启动所有服务
python app.py

# 或分别启动
python -m src.collector.syslog_collector  # Syslog接收
python -m src.api.server                   # API服务
python -m src.web.app                      # Web界面
```

### 3.2 生产环境启动

```bash
# 使用 nohup 后台运行
nohup python app.py > app.log 2>&1 &

# 或使用 systemd 服务
sudo vim /etc/systemd/system/vip-query.service
```

#### systemd 服务配置

```ini
[Unit]
Description=aTrust VIP Query Service
After=network.target

[Service]
Type=simple
User=www-data
WorkingDirectory=/opt/vip-query
ExecStart=/opt/vip-query/venv/bin/python app.py
Restart=always
RestartSec=10

[Install]
WantedBy=multi-user.target
```

```bash
# 启用服务
sudo systemctl daemon-reload
sudo systemctl enable vip-query
sudo systemctl start vip-query

# 查看状态
sudo systemctl status vip-query
```

### 3.3 Docker 部署（可选）

```dockerfile
FROM python:3.10-slim

WORKDIR /app

COPY requirements.txt .
RUN pip install -r requirements.txt

COPY . .

EXPOSE 514/udp 8000 8501

CMD ["python", "app.py"]
```

```bash
# 构建镜像
docker build -t vip-query .

# 运行容器
docker run -d \
  --name vip-query \
  -p 514:514/udp \
  -p 8000:8000 \
  -p 8501:8501 \
  -v ./data:/app/data \
  -v ./config.yaml:/app/config.yaml \
  vip-query
```

## 四、配置 aTrust

### 4.1 配置 Syslog 转发

1. 登录 aTrust 控制台
2. 进入 **审计中心 → 外置日志中心 → 第三方Syslog**
3. 添加 Syslog 服务器：

| 配置项 | 值 |
|--------|-----|
| 服务器名称 | VIP查询服务器 |
| 服务器地址 | 你的服务器IP |
| 端口 | 514 |
| 协议 | UDP |
| 日志类型 | 用户日志 |

4. 保存配置

### 4.2 验证 Syslog 连通

```bash
# 在服务器上监听514端口
sudo tcpdump -i any udp port 514

# 或使用 nc
nc -lu 514
```

## 六、常见问题

### 6.1 端口占用

```bash
# 查看端口占用
lsof -i:514
lsof -i:8000
lsof -i:8501

# 杀死占用进程
kill -9 <PID>
```

### 6.2 权限问题

```bash
# Linux下使用1024以下端口需要root权限
sudo python app.py

# 或配置端口映射
iptables -t nat -A PREROUTING -p udp --dport 514 -j REDIRECT --to-port 1514
```

### 6.3 防火墙配置

```bash
# 开放端口
sudo ufw allow 514/udp
sudo ufw allow 8000/tcp
sudo ufw allow 8501/tcp

# 或使用 firewalld
sudo firewall-cmd --permanent --add-port=514/udp
sudo firewall-cmd --permanent --add-port=8000/tcp
sudo firewall-cmd --permanent --add-port=8501/tcp
sudo firewall-cmd --reload
```

### 6.4 aTrust API 连接失败

```bash
# 检查网络连通性
telnet 192.168.1.100 4433

# 检查证书（如果使用自签名证书）
curl -k https://192.168.1.100:4433/api/v1/admin/getConfig
```

## 七、监控与维护

### 7.1 日志查看

```bash
# 查看应用日志
tail -f app.log

# 查看Syslog接收日志
tail -f syslog.log
```

### 7.2 数据库维护

```bash
# 备份数据库
cp data/vip_data.db data/vip_data_backup_$(date +%Y%m%d).db

# 清理旧数据
sqlite3 data/vip_data.db "DELETE FROM vip_records WHERE timestamp < datetime('now', '-90 days');"
```

### 7.3 服务重启

```bash
# systemd方式
sudo systemctl restart vip-query

# 手动方式
pkill -f "python app.py"
nohup python app.py > app.log 2>&1 &
```

## 八、卸载

```bash
# 1. 停止服务
sudo systemctl stop vip-query
sudo systemctl disable vip-query

# 2. 删除服务文件
sudo rm /etc/systemd/system/vip-query.service

# 3. 删除项目文件
rm -rf /opt/vip-query

# 4. 删除数据库（可选）
rm -f data/vip_data.db
```
