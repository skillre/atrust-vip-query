# aTrust 用户虚拟IP快速查询系统 - MVP

## 一、项目概述

### 1.1 项目背景

深信服 aTrust 零信任系统会为接入用户分配虚拟IP地址，运维人员需要频繁查询用户的虚拟IP用于问题排查和安全审计。

**当前痛点：**

- 在线用户：需登录控制台手动查询
- 离线用户：需翻阅登录日志查找
- 查询效率低，无法快速定位

### 1.2 项目目标

构建一个轻量级 MVP 系统，实现：

- ✅ 查询在线用户虚拟IP
- ✅ 查询历史虚拟IP记录
- ✅ 按虚拟IP反查用户
- ✅ 多种查询方式（用户名、显示名、手机号）
- ✅ 快速响应（< 2秒）
- ✅ 支持日志文件导入（无需直连设备）

### 1.3 运行模式

系统支持两种运行模式：

| 模式 | 说明 | 适用场景 |
|------|------|----------|
| **导入模式**（默认） | 通过 Web 界面上传 aTrust 导出的日志文件 | 设备无法通过网络访问 |
| **实时模式** | 实时连接 aTrust 设备，自动采集数据 | 设备可通过网络访问 |

### 1.4 技术选型

| 组件 | 技术方案 | 说明 |
| ------ | --------- | ------ |
| 后端框架 | FastAPI | 高性能、自动生成API文档 |
| 前端界面 | Streamlit | 快速搭建、无需前端开发 |
| 数据库 | SQLite | Python内置、零配置、单文件存储 |
| 数据采集 | 文件导入 + API/Syslog | 支持离线和实时两种方式 |

| 组件 | 端口 | 职责 |

## 四、数据存储

### 4.1 数据库选型

**使用 SQLite**，理由：

- Python 内置，无需额外安装
- 单文件存储，便于备份迁移
- 轻量级，适合 MVP 阶段
- 足够支撑万级数据量

### 4.2 数据表设计

详见 [数据库设计文档](./docs/02-数据库设计.md)

### 4.3 数据保留策略

| 数据类型 | 保留时长 | 说明 |
| --------- | --------- | ------ |
| 用户信息 | 永久 | 基础数据，手动维护 |
| 虚拟IP记录 | 90天 | 自动清理过期记录 |
| Syslog原始日志 | 不存储 | 只提取关键字段 |
